# Dirtpickle Music Archive

Central archive for music developed with ChatGPT across the Music Creation project.

## Organization

- `albums/cathedral-of-static/` — the current complete dark-musical/concept-album sequence.
- `songs/the-fall/` — standalone development for **The Fall**.
- `sketches/` — riffs, motifs, experiments, alternates, and loose ideas.
- `incoming/` — landing area for new tracks before they are classified.

## Working rule going forward

When a new music artifact is created and GitHub access is available in the conversation, archive the useful version here and update the relevant index. Keep meaningful alternates/version history rather than silently replacing materially different arrangements.

## Recovery status

Some historical ChatGPT music artifacts are represented in the Library by notes/metadata but their original MIDI/audio binaries are not always directly exposed through Library search. This archive distinguishes recovered source files from known material that still needs its original binary recovered. When an original MIDI/audio file is available in a conversation, it should be archived beside its song notes here.
